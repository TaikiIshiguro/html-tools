# html-tools
HTML/CSS/JavaScriptで動作するちょっとしたツール集です。

ツールのデザインに当たっては，[デジタル庁デザインシステム](https://design.digital.go.jp/dads/)を参考にしています。

## 画像モザイク

画像の指定範囲にモザイクをかけるツールです。

- モザイク範囲は，四角形・円・フリーハンドに対応。
- モザイクの粗さを設定可能。
- クリップボードからの画像貼り付けに対応。


## Mermaidビューワー

Mermaidの編集・プレビュー・画像ダウンロードができます。

## QRコード作成

さまざまなQRコードを作成できます。

- テキスト
- URL
- メール送信
- Wi-Fi接続情報
- 電話番号
- SMS送信
- 連絡先 vCard

## PDF黒塗り

情報公開で開示するPDFの非公開情報を黒塗りするツールです。

- 黒塗りすると同時にラスタライズを行い，テキスト情報や隠れたレイヤーの情報を削除します。
- 黒塗り方法は，四角形・円・フリーハンドに対応
- 公開用の黒塗りファイルに加え，起案用に非公開範囲を赤枠で囲んだファイルも出力できます。

## 動画・音声プレイヤー
ブラウザでの動画・音声再生に，あったら便利な機能をいろいろ追加しました。

- 再生速度は0.1倍単位で自由に設定可能。（0.1倍～16倍）
- 動画を1フレーム単位で進める・戻る。
- 動画のフレームを画像として保存。
- 特定の個所にフラグを立てて簡単にスキップ。
- 各種ショートカット対応。
